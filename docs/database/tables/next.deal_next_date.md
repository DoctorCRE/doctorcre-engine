# next.deal_next_date

<summary><strong>Table Definition</strong></summary>

```sql
CREATE VIEW deal_next_date AS (
 SELECT DISTINCT ON (deal_id) deal_id,
    due_on
   FROM next_step s
  WHERE ((deal_id IS NOT NULL) AND (item_title IS NULL) AND ((status = 'open'::text) OR (EXISTS ( SELECT
           FROM proposal p
          WHERE ((p.next_step_id = s.id) AND p.keeps_deal_date AND (p.decided_at = s.done_at) AND (NOT (EXISTS ( SELECT
                   FROM next_step newer
                  WHERE ((newer.deal_id = s.deal_id) AND (newer.item_title IS NULL) AND (newer.created_at > p.decided_at))))))))))
  ORDER BY deal_id, created_at DESC, id DESC
)
```
