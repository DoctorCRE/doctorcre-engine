The drawing PR says **Part of #1519**. Completion of the slices closes the issue.

Check database invariants through direct writes under the engine role as well as by opening the normal door. Run the engine check after each engine slice and the app check after each app slice. During the staging run-through, record a failed step, use a stand-in result to continue, then rerun from the beginning after fixes.

## Staging run-through

Start with a made-up lease deal for a starting practice and a comparable deal without a stage. Approve the lease workflow, a practice addition, a sourced rule, an observation, and a lender term. Open both deals, save a skip and an override, then compare the deal page, Plan, vendor, and Doc reads. Release a preview, change the source value, and open both the live read and the released copy. Expect every common to-do on both deals, the scoped addition on only the matching deal, the exception reasons visible to the partner, Doc quoting the current source, and the download retaining the approved content. Run the same exercise as the other partner and a job with a private draft present. Expect no disclosure through any door or change projection.

Use the existing engine and app checks. The cutover work updates the current system map and screen wiring when the new read replaces the old checklist definition.
