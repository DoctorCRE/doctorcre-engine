# Relationships

- [ ] On a computer the network, Suggested introductions and the Directory show on one screen. The network fills the height. A column beside it holds Suggested introductions and the Directory, and each scrolls inside itself. The page does not scroll and nothing scrolls sideways at 1280 and 1440 wide, with Today open or closed. On a phone the page scrolls.
- [ ] Search, the filters, the update time and refresh share one toolbar row. On a phone the filters fold under Filter. Clear filters undoes them all.
- [ ] Today starts collapsed on Relationships and keeps each partner's own choice, as on Vendors.
- [ ] The Directory lists 50 records at a time. **Show more** adds the next 50 and moves focus to the first new row. The count beside Directory covers every record, not only the rows shown.
- [ ] Every record reads as a name. A name that is only a bracketed note, a bare website such as `demo-site.com`, or digits reads `Unnamed <kind> (<text>)`, such as `Unnamed client (demo note)`, and sorts after the named records. A name like `Dr.Lee`, `Realtor.com` or `(Demo) Dental (North)` stays as written.
- [ ] A name that is only an old record code, such as `C-013`, reads `<Kind> at <record>`, naming the record that carries that code, such as `Contact at Demo Dental`. A code no record carries reads "An old record". A `(C-013)` tag after a name is dropped.
- [ ] An old record code inside an introduction reason or a link note reads the same way. A code after Suite, Unit, Ste, Lot or `#` stays, so "Suite C-100" reads as written.
- [ ] No record is hidden for its name. Search matches the name as shown. The relationship card uses the same names as the Directory.
